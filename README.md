# しずく日記

SNS依存から少しずつ距離をおくための、ローカル完結型のジャーナル（日記）アプリです。
サーバーは使わず、書いた内容はすべて自分のブラウザの中（localStorage）だけに保存されます。

## 主な機能

- **今日の記録**：気分を「あらし〜快晴」のダイヤルで記録、SNSを開きたい衝動の有無ときっかけ、今日の感謝、自由記述
- **記録**：過去に書いたページを一覧・展開表示
- **統計**：連続記録日数、合計ページ数、衝動がなかった日の割合、気分の推移グラフ、衝動のきっかけ内訳
- **設定**：記録をJSONファイルとして書き出し／読み込み、全消去

## ローカルで使う

ダウンロードして展開したフォルダの中の `index.html` を、ブラウザ（Chrome / Safari / Edge など）でダブルクリックして開くだけで動作します。インストールや設定は不要です。

```
sns-detox-journal/
├── index.html
├── styles.css
├── script.js
└── README.md
```

> データはブラウザごと・端末ごとに保存されます。別のブラウザや端末で開くと記録は空になります。定期的に「設定」タブからJSONを書き出してバックアップしておくのがおすすめです。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成します（例: `sns-detox-journal`）。
2. このフォルダの中身（`index.html` など）をリポジトリのルートに追加してコミット・プッシュします。

   ```bash
   git init
   git add .
   git commit -m "しずく日記を追加"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```

3. GitHubのリポジトリページで **Settings → Pages** を開きます。
4. 「Build and deployment」の **Source** を `Deploy from a branch` に設定し、**Branch** を `main` / `/(root)` にして **Save** します。
5. 数分待つと、`https://<あなたのユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。

公開後もデータはあくまで各訪問者のブラウザ内に保存されるだけで、あなたを含め誰にも送信されません。

## データについて

- 保存先はブラウザの `localStorage` のみです。外部サーバーへの通信は一切行いません。
- 「設定」タブの「記録を書き出す」でいつでもJSON形式のバックアップを取れます。
- 「記録を消去」は取り消せません。実行前に書き出しておくことをおすすめします。

## カスタマイズ

- 配色やフォントは `styles.css` の先頭にある `:root` 変数でまとめて管理しています。
- 衝動のきっかけの選択肢は `index.html` 内の `#triggerChips` を編集すると増減できます。
